# NACIS 上海诺达 · 八年级理科实验室

本地动态学习站：专有名词英汉对照、选择题、判断题、元素周期表、相对原子质量。

面向 **上海诺达双语学校（Nord Anglia Chinese International School Shanghai）** 八年级理科，内容对齐上海课标基础 + 双语 IGCSE 衔接。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

## 功能

| 模式 | 说明 |
|------|------|
| 单词翻转卡 | 英↔汉专有名词，含记忆提示 |
| 英汉配对 | 游戏化配对练习 |
| 选择题 / 判断题 | 错了立刻显示正确答案与解析 |
| 元素周期表 | 浏览 + 符号/中文名/Ar 测验 |
| 相对原子质量 | 背 Ar、算 Mr |
| 综合随机测 | 三科混合抽题 |
| 错题本 | 本地自动收录薄弱题 |

进度（XP、连击、错题）保存在浏览器 `localStorage`。

## 内容范围（Grade 8）

- **物理**：声、光、运动和力（沪教方向）
- **生物 / 生命科学**：人体生命活动、调节与健康
- **化学**：空气/氧气/二氧化碳/水、原子分子元素、周期表、相对原子质量与化学式
