# Alex Practice

上海诺达 **NACIS** · Grade 8 理科拔尖 · **中 / 英 / 双语可切换**  
UI 复刻 **Wayground（原 Quizizz）** 答题模式。

## 更新并启动

```bash
cd NACIS-Tomhub
git pull
npm install
npm run dev
```

打开 **http://localhost:5173/**

右上角：**中 | 双语 | EN** 语言切换，♪ 音效开关。

## 内容（对齐 NACIS 八年级）

| 模块 | 规模 |
|------|------|
| 专有名词 | ≈560+ |
| 题目 | ≈420（题干 / 选项 / 解析双语） |
| Daily Days | Day 1–28，每天 ≈36 词 + ≈28 **课标核心**题 |

覆盖沪教八年级 + 诺达双语：

- **物理**：声、光与透镜、运动和力（密度/压强等衔接按课标）
- **生物**：人体结构与生命活动、神经/激素调节、免疫与健康
- **化学**：空气与水、元素化合物、原子分子、周期表与相对质量

另有少量 **IGCSE 拔高**题，自由练习里可用「含拔高」筛选；Daily Days 仅用课标核心题。

## 功能

- 语言三档：**中文 / 双语 / English**
- Wayground 风答题 + 升级游戏音效（可关）
- Daily Days 一条龙、闪卡、配对、周期表、Ar/Mr、错题本
