# Tom's Ground

上海诺达 **NACIS** · 八年级全科拔尖练习站  
首页六大学科入口：**语文 / 数学 / 英语(雅思) / 物理 / 化学 / 生物**

## 启动

```bash
cd NACIS-Tomhub
git pull
npm install
npm run dev
```

打开 http://localhost:5173/
